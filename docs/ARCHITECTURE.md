# VERDICT architecture

Welcome → Analyst Access → Command Center → Case Intake → Investigation → Evidence Dossier → Cross-Examination → Contradiction Check → Trust Assessment → Verdict → Disposition → Audit.

The investigation layer covers data integrity, model integrity, inference provenance/output integrity, and distribution-shift/anomaly assessment. Evidence is linked before the confidence-aware trust assessment is rendered.

The runtime is local and deterministic for demonstration. Synthetic scenarios are reproducible. White-box model checks are unavailable in the demo and are represented by a behavioral fallback with an explicit limitation.
