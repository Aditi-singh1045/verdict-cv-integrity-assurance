# VERDICT demo script

1. Open the local welcome page and explain that VERDICT is an offline evidence-based assurance workspace.
2. Sign in with any demonstration Analyst ID and Access Key.
3. In Command Center, show the four assurance domains, evidence ledger, six reproducible Scenario Lab conditions, and the ten-stage pipeline.
4. Start a new investigation. Case Intake registers contributor material, dataset, model, and inference/output context; the analyst does **not** select the final verdict.
5. For a controlled demonstration, choose a condition from the Scenario Lab. This injects a known synthetic test condition; it is not the expected verdict.
6. Let the one-by-one investigation stages run.
7. On the final assurance report, show the final trust assessment, confidence, evidence dossier, cross-examination, contradiction check, technical verification, operational disposition, and tamper-evident audit trail.
8. Explain the distinction: TRIGGER, OOD, and DUPLICATE FLOOD are investigated conditions; TRUSTWORTHY, REVIEW, and COMPROMISED are possible final trust assessments in this prototype.
9. Click RUN ANOTHER LAB TEST to retain case metadata and demonstrate another controlled condition.
